## Development Philosophy

I believe in learning technologies by understanding how they actually work and then applying them through practical implementation.

My learning approach:

```text
Learn the concept
      ↓
Understand why it is needed
      ↓
Understand how it works
      ↓
Implement it
      ↓
Test it
      ↓
Handle common failures
      ↓
Apply production considerations
```

My goal is to understand the technology behind the application, not just make the application work.

## Portfolio

This folder is the personal portfolio website.

The website is built using:

- HTML
- CSS
- Vanilla JavaScript

It uses **no build step and no JavaScript framework dependencies**.

The page opens with a handwritten **hello**, then reveals the editorial portfolio.

### Run Locally

Open `index.html` directly in your browser.

Or run a local server from this folder:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
